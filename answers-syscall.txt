What was the previous mode that the CPU was in?
The previous mode the CPU was in is 0x22 which is user mode.

Write down the assembly instruction the kernel is panicing at. Which register corresponds to the varialable num?
The asm instruction is:
lw	a3,0(zero) # 0 <_entry-0x80000000>
Register a3 is num.

The kernel crashes because it is trying to access address 0 which is not mapped in the kernel address space.
