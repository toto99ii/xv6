Which registers contain arguments to functions? For example, which register holds 13 in main's call to printf?
In riscv a0-a7 hold the first 8 arguments to functions. In main's call to printf, a2 holds the value 13.

At what address is the function printf located?
printf is located at address 0x0000000000000630.

What value is in the register ra just after the jalr to printf in main?
ra is set to the return address 0x38

Run the following code.
```
unsigned int i = 0x00646c72;
printf("H%x Wo%s", 57616, &i);
```
What is the output? The output is "HE110 World".
The output depends on that fact that the RISC-V is little-endian. If the RISC-V were instead big-endian what would you set i to in order to yield the same output? i=0x726c6400
Would you need to change 57616 to a different value? No

In the following code, what is going to be printed after 'y='? (note: the answer is not a specific value.) Why does this happen?
```
printf("x=%d y=%d", 3);
```
The output will be garbage value for y. This happens because printf expects two arguments for the format string, but only one argument is provided. The second argument for y is not defined, leading to it being what previously was in the a1 register, which could be any value.
